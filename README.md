# Buchungsseite
Webbasiertes Buchungssystem für mein kleines Hotel mit Zimmern 101–105, 201–205, zwei Apartments 301 und Familienzimmer 11. Online-Kalender mit klarer Anzeige von Name, Zeitraum und Personenzahl. Responsive für PC und Smartphone. Direktbuchung über Homepage mit Echtzeit-Eintragung. Später API-Anbindung an Booking und Website.
